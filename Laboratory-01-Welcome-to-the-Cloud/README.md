# Mission 1 - Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment using KillerCoda. I explored the Linux environment, created a new user, gathered system information, and prepared my Cloud Computing portfolio repository on GitHub.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

I accessed an Ubuntu 24.04 environment through KillerCoda. I created a Linux user named pmata and logged in to the account. I also gathered information about the Linux distribution, kernel, CPU, memory, and available disk space. I created the required workspace and prepared my GitHub repository.

## Linux Commands Used

- `sudo adduser pmata`
- `sudo usermod -aG sudo pmata`
- `su - pmata`
- `whoami`
- `pwd`
- `hostname`
- `cat /etc/os-release`
- `uname -r`
- `lscpu`
- `free -h`
- `df -h`
- `mkdir`
- `cd`
- `touch`
- `nano`
- `cat`

## Skills Learned

I learned how to access and work with a Linux environment, create and manage users, gather system information, organize files and directories, and document my work using Markdown and GitHub.
