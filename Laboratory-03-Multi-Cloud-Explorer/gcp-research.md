## Google Cloud Platform (GCP)

### Overview
Google Cloud Platform (GCP) is a cloud platform that provides infrastructure, computing, storage, database, networking, and other cloud services.

### Services Explored
- Compute
- Storage
- Databases
- Networking

### Strengths
- Strong data and analytics capabilities
- Scalable infrastructure
- Integration with Google technologies

### Pricing Model
GCP uses pricing based on the cloud resources and services consumed.

### Target Users
GCP can be used by developers, organizations, businesses, and enterprises.
